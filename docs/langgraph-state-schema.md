# LangGraph Agent State Schema

## 1. Overview

The Adaptive MAS-RCA system uses a shared state object for
communication between multiple RCA agents.

The state is implemented using Python TypedDict.

## 2. Shared State Fields

| Field | Type | Description |
|---|---|---|
| raw_inputs | Dict[str, Any] | Original incident and system input data |
| agent_outputs | Dict[str, Any] | Outputs generated by individual agents |
| confidence | Dict[str, float] | Confidence scores produced by agents |
| final_report | Optional[str] | Final RCA report |
| trace_id | str | Unique identifier for one RCA execution |

## 3. Agent State Access

| Agent | Reads | Writes |
|---|---|---|
| Log Analysis Agent | raw_inputs | agent_outputs, confidence |
| Dependency Analysis Agent | raw_inputs, agent_outputs | agent_outputs, confidence |
| Root Cause Analysis Agent | raw_inputs, agent_outputs | agent_outputs, confidence |
| Validation Agent | agent_outputs, confidence | agent_outputs, confidence |
| Report Agent | raw_inputs, agent_outputs, confidence | final_report |

## 4. State Flow

raw_inputs
    ↓
Log Analysis Agent
    ↓
Dependency Analysis Agent
    ↓
Root Cause Analysis Agent
    ↓
Validation Agent
    ↓
Report Agent
    ↓
final_report

## 5. Traceability

The trace_id field uniquely identifies an RCA execution.

All agent outputs and the final report can be associated
with the same trace_id.
