# Adaptive MAS RCA

Adaptive Multi-Agent Root Cause Analysis System.

## Overview

Adaptive MAS RCA is a multi-agent system designed to identify,
analyze, and explain root causes using multiple specialized agents.

## Objectives

- Automated root-cause analysis
- Multi-agent collaboration
- Evidence collection and analysis
- Root-cause ranking
- Confidence-based diagnosis
- Explainable RCA results

## Technology Stack

- Python
- Node.js
- Docker
- Git
- GitHub

## Branching Strategy

- `main` — stable production-ready code
- `develop` — integration and development
- `feature/*` — individual feature development
